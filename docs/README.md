# وثائق عون الدرب

ست وثائق، كلٌّ منها بصيغتين: `.html` هي المصدر، و`.pdf` هي النسخة التي تُرسَل
وتُطبع. لا يُشحن شيء من هذا المجلّد إلى الموقع — `build.js` يعمل بقائمة سماح،
فما ليس مذكوراً فيها لا يُنسخ إلى `dist/`.

| الوثيقة | ما فيها |
|---|---|
| `دليل-المشغل` | كيف تُدار اللوحة يوماً بيوم: الطلبات، المحتوى، النسخ الاحتياطي، الاستعادة |
| `خريطة-عون-الدرب-التجارية` | الخريطة التجارية — الخدمات والجمهور والحدود المعتمدة |
| `بنية-نظام-عون-الدرب` | بنية النظام: الواجهة العامة، الـAPI، الصلاحيات، قاعدة البيانات |
| `الموجه-الرئيسي-عون-الدرب` | الموجّه الرئيسي للمشروع وقراراته الثابتة |
| `ورقة-رصد-جلسة-عون-الدرب` | ورقة رصد جلسة العمل |
| `Aoun-Al-Darb-System-Status-Report` | تقرير حالة النظام بالإنجليزية (A4، خمس صفحات) |

## ملاحظة على ملفات PDF

لا يوجد سكربت يولّدها. أُنتجت يدوياً من ملفات `.html` المجاورة في جلسة سابقة،
ولم تُحفظ تلك الخطوة. ولهذا هي متتبَّعة في git ولم يُلغَ تتبّعها مع `dist/`
وصور المقاسات: تلك مُشتقّة **ويمكن إعادة توليدها بأمر**، وهذه مُشتقّة ولا يمكن.

ملفات `.html` تجلب خطوطها من Google Fonts، فطباعتها في بيئة بلا وصول إلى
Google تُنتج خطوطاً بديلة — وهو سبب آخر لعدم التعامل معها كملفات يُعاد
توليدها متى شئنا. إن احتيج لتوليدها آلياً لاحقاً، فالمطلوب سكربت يستبدل ذلك
الرابط بخطوط المشروع المحلية في `fonts/` مضمَّنةً، ثم يطبع بقياس A4.
