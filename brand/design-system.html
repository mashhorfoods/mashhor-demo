نظام تصميم موقع عون الدرب

نظام بصري وتفاعلي واحد قابل لإعادة الاستخدام، يرثه كل قسم مستقبلي — مبني منذ البداية لـ RTL العربية، والوصول، والأداء، والتجاوب. هذه المرحلة نظام فقط: لا تُصمَّم أي أقسام صفحة.

الوصول

الوصول جزء من النظام لا ترقيع لاحق — وهو جوهر علامة تخدم كبار السن وذوي الإعاقة.

تباين WCAG

نص أساسي كحلي/حبر ≥4.5:1؛ الأزرق للعناصر الكبيرة والواجهات.

تركيز مرئي

حلقة تركيز على كل عنصر عبر لوحة المفاتيح.

أهداف لمس ≥44px

أزرار وروابط وحقول قابلة للاستخدام باللمس.

بنية دلالية

هرمية عناوين، roles، skip-link، وبدائل نصية للصور.

لا لون وحده

أي دلالة تُرفق بأيقونة أو نص.

حركة مخفّضة

تعطيل الحركة عند prefers-reduced-motion.

21

الأداء

النظام يدعم موقعًا عالي الأداء: CSS واحد بلا تبعيات ثقيلة، أيقونات SVG مضمّنة خفيفة، حاويات صور بنسب ثابتة تمنع انزياح التخطيط (CLS)، وحركة مقيّدة دون parallax مفرط أو JS غير ضروري.

بلا تبعيات

توكنز + CSS نقي؛ لا أطر ثقيلة.

أبعاد متوقّعة

aspect-ratio لكل صورة — لا قفز تخطيط.

أصول خفيفة

لوجو SVG متجهي، أيقونات مضمّنة.
