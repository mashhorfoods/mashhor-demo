# Image credits

Every file under `assets/images/` is supplied directly by the business. No
third-party licence or attribution applies.

To replace any single photo, drop a new file in at the same slot path (see
`assets/js/data/images.js` for the full slot list) and update its entry
there — the slot key never changes, so nothing else in the codebase needs
to. To add a new slot, add both the file and its `IMAGES` entry.
